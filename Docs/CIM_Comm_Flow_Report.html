CIM 통신 흐름 분석 보고서

작성일: 2026.02.13 | 분석 데이터: Log_2025-11-06_Log.txt

1. 개요

본 보고서는 CIM(Communication & Interface Module)의 핵심 통신 시퀀스와 메시지 흐름을 분석한 결과입니다.

CIM 시스템은 상위 Host 시스템과 장비 시뮬레이터(Simulator) 사이의 가교 역할을 수행하며, SECS-II 표준 프로토콜을 사용하여 실시간 인터페이스를 제어합니다.

2. 주요 통신 시나리오

A. Glass 로딩 및 공정 시작 (Single Cycle)

Host로부터 레시피 확인 및 Glass 데이터를 수신하고, 장비로 이동 명령을 내린 후 공정을 시작하는 단계입니다.

sequenceDiagram participant Host as Host (CIM Server) participant CIM as TOECIM (Main) participant Sim as EQP Simulator Note over Host, Sim: 1. Recipe & Data Receive Host->>CIM: S7F61 (Recipe ID Confirm Req) CIM-->>Host: S7F62 (Ack) Host->>CIM: S2F87 (Load Glass Data) CIM-->>Host: S2F88 (Ack) Note over Host, Sim: 2. Glass Movement (LR) CIM->>Sim: Glass Move Req (LR) CIM->>Host: S6F67 (Move Request: LR) Host-->>CIM: S6F68 (Ack) Note over Host, Sim: 3. Load Done & Status Report Sim->>CIM: CMD: LoadDone CIM->>Host: S6F91 (Status Change: RUN) Host-->>CIM: S6F92 (Ack) CIM->>Host: S1F67 (All Glass Position Report) Host-->>CIM: S1F68 (Ack)

B. Glass 교체 및 언로딩 (Exchange Flow)

검사가 완료된 Glass를 배출하고 새로운 Glass를 투입하는 시퀀스입니다.

sequenceDiagram participant Host as Host (CIM Server) participant CIM as TOECIM (Main) participant Sim as EQP Simulator Note over Host, Sim: 1. Inspection Done Sim->>CIM: CMD: InspectDone CIM->>Host: S6F11/S6F91 (Status Change Report) Note over Host, Sim: 2. Exchange Ready Sim->>CIM: CMD: ExchangeReadyDone CIM->>Host: S6F63 (Unload Glass Data Report) Host-->>CIM: S6F64 (Ack) CIM->>Host: S6F61 (Load Glass Data Req) Host-->>CIM: S6F62 (Ack) Note over Host, Sim: 3. Move Req (UW/ER) Host->>CIM: S2F87 (New Glass Data) CIM->>Sim: Move Req (UW/ER) CIM->>Host: S6F67 (Move Request) Host-->>CIM: S6F68 (Ack) Note over Host, Sim: 4. Exchange Done Sim->>CIM: CMD: ExchangeDone CIM->>Host: S1F67 (Glass Position Report) Host-->>CIM: S1F68 (Ack)

C. LOT 종료 (LOT End)

해당 LOT의 모든 공정이 완료되어 데이터를 최종 보고하는 단계입니다.

sequenceDiagram participant Host as Host (CIM Server) participant CIM as TOECIM (Main) Host->>CIM: S6F65 (LOT End Data Send) CIM-->>Host: S6F66 (Ack) CIM->>Host: S6F83 (LOT Actual Processing Data Report) CIM-->>Host: S6F84 (Ack)

3. 로그 분석 특이 사항

  • 1. lastValue.json 파일 접근 충돌 (Race Condition)

    TOECIM.CIMStatus.Save() 호출 시 파일이 다른 프로세스에 의해 사용 중이라는 에러가 빈번하게 발생하고 있습니다.

    조치 권고: 파일 쓰기 시 Lock 메커니즘을 도입하거나 비동기 큐를 통한 순차 저장이 필요합니다.
  • 2. SendS6F73 NullReferenceException

    ClientCIM.SendS6F73() 메서드 호출 시 개체 참조 오류가 발생하고 있습니다.

    조치 권고: 해당 메서드 내에서 사용하는 객체(예: HSMSGem 등)의 초기화 여부를 확인하고 Null 가이드 로직을 보강해야 합니다.
  • 3. Console 연결 끊김 및 타임아웃

    ReqEqData 호출 시 'Console 연결되지 않음' 에러가 발생하며 서버 연결이 수시로 끊기는 현상이 관찰되었습니다.

    조치 권고: 네트워크 안정성 점검 및 재접속 로직의 지수 백오프(Exponential Backoff) 방식 적용을 고려해야 합니다.
